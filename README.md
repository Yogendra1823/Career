# 🎓 Assistant Career Guidance Platform

**Assistant Career Guidance Platform** is a modern, web-based student guidance system that helps students after Class 10 and 12 choose the right **streams, courses, and careers**.  
It’s built to empower students with personalized AI recommendations, career quizzes, and verified college data — all through an intuitive and responsive interface.

---

🔗 **Live Site:** [assistantcareerguidance.netlify.app](https://assistantcareerguidance.netlify.app)

---

## ✨ Features

🎯 **AI-Powered Career Suggestions**  
Get personalized recommendations based on your quiz results and interests.

🧠 **Career Quiz System**  
Discover suitable streams and professions through interactive quizzes.

🏫 **College Directory**  
Explore colleges by course, stream, and location — powered by Supabase database.

📚 **Educational Resources**  
Access curated guides, career tips, and learning materials.

📢 **Admission & Scholarship Alerts**  
Stay informed about government schemes and educational opportunities.

💬 **AI Chat Assistant**  
Get real-time academic and career guidance using Gemini API.

📱 **Responsive Design**  
Optimized for mobile, tablet, and desktop viewing.

---

## 🚀 Tech Stack

**Frontend:** React, Vite, Tailwind CSS  
**Backend:** Supabase (Auth, PostgreSQL Database, Edge Functions)  
**AI Integration:** Gemini API (Career Guidance AI)  
**Hosting:** Netlify  

---

## 🗄️ Supabase Database Overview

**Tables Used:**
- `students` → Stores student profiles and preferences  
- `quiz_results` → Holds quiz data and AI recommendations  
- `colleges` → Contains verified college listings  
- `resources` → Lists articles, study materials, and guides  

Supabase handles:
- 🔐 **Auth** (Email/Password sign-in)  
- 🧾 **Data storage** (PostgreSQL)  
- ⚡ **Edge Functions** (API integration with Gemini AI)
